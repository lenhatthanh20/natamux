This version adds Git blame annotations, reports agent sign-in screens and early launch failures, and fixes stage status after permission waits. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Desktop app

- Right-click a file's editor or the **Changes** diff and choose **Annotate with Git Blame**. Each line shows the date and author of its last change. Right-click an annotated line to see its commit, **Copy Commit Hash**, or **Close Annotations**. Save editor changes before turning annotations on. See [Changes and History](https://natamux.github.io/docs/guides/changes-and-history/).

## Agents

- When an agent shows a known sign-in screen in the first 30 seconds after launch, the task moves to **Needs input**. The sidebar and stage card show the sign-in line and the terminal to open. Sign in there to continue. See [Agent sign-in](https://natamux.github.io/docs/help/troubleshooting/#the-agent-asks-me-to-sign-in).
- Fix: an agent could exit with an error just after launch without a clear task failure. An error exit in the first 30 seconds, before the agent reports anything, now fails the task and shows its last line and terminal.
- Fix: Cursor and Copilot stages could keep showing **Needs input** after a permission was answered. Tool completion now clears a permission or bell wait, including after a restart. Explicit questions still wait for an answer.

## Fixes

- Fix: bundled SQLite could expose memory when a database and its WAL file had different page sizes. Update SQLite to 3.54.1.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
