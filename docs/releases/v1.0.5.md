In the desktop app you can now remove a workspace or delete a task even when its worktree has files that are not committed. This release also fixes two bugs. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Tasks

- In the desktop app, when a task's worktree has files that are not committed, **Remove workspace** lists them and offers **Remove anyway**. It then shows what goes and what stays, with "Discards N files that are not committed." first, and the button **Discard and remove**. **Delete task** names those files too and reads **Delete anyway**. The finished banner no longer disables **Remove workspace** for them. A folder that is not a git worktree, or a locked worktree, is still refused, and the branch rules do not change. The web dashboard, the CLI and **Remove finished workspaces** still refuse. For scripts, add `force=true` to `DELETE /tasks/:id` or `DELETE /tasks/:id/workspace`. See [When a task is finished](https://natamux.github.io/docs/guides/dashboard/#when-a-task-is-finished).

## Fixes

- In the v1.0.4 desktop app for Apple silicon on macOS 26, the green traffic light touched the first letter of the title bar. Now there is a gap between them.
- In the desktop app sidebar, the hover of the "N finished" row stopped before its **Remove finished workspaces** button, so the button looked like it sat outside the row. Now the hover covers the whole row.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
