This version fixes the Progress flow (node names, tooltips, stage details) and lets Codex report done from its sandbox. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Fixes

- Fix: the first Context node in **Progress** sat close to the summary strip. It now has more space above it.
- Fix: a stage in an **If** branch opened its details below the whole branch. Its details now open directly below the stage node.
- Fix: the line through a skipped Progress node's name ran past the words. It now covers only the words.
- Fix: hovering a Progress node showed a tooltip that covered the stages around it. A node has no tooltip now; click it to see its state, time, cost and agent.
- Fix: a Progress node's name sat too far from its tile. It now sits closer to the tile.
- Fix: a stage run by Codex in the auto mode could not report done, because the Codex sandbox blocked the network. Codex can now reach the daemon from its sandbox.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
