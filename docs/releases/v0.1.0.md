The first release of Natamux: run many coding agents in parallel, each task in its own git worktree and terminal, every task's state on one dashboard.

Guide: https://natamux.github.io/docs/

## What is in it

- **Tasks and a dashboard.** A table and a board of every task, with a "Needs you" strip that names the task waiting for you. Keyboard first (`⌘K` / `Ctrl+K`).
- **A worktree per task.** Each task gets its own branch and folder, so agents never step on each other.
- **Five agents:** Claude Code, Codex, Gemini CLI, GitHub Copilot CLI and Cursor. Natamux adds hooks for each session, so the dashboard knows when an agent works, asks or is done.
- **Stages:** Context → Spec → Plan → Test spec ‖ Implement → Review → Testing → Release. Change them per project in `.natamux.json`. Each stage checks its result before it moves on.
- **Changes and history.** A file tree and side by side or inline diffs, commit and push, open a pull request, and a branch graph.
- **The `natamux` command**, short name `nmx`, for you and for agents (`natamux done`, `natamux ask`).
- **Runs in your browser or as a desktop app.** No account and no telemetry.

## Before you open it

This release is **not signed** with an Apple certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Ubuntu 24.04 and later, AppImage:** the system can block Chromium's sandbox. Install the `.deb` instead, or start the AppImage with `--no-sandbox`.

You need at least one agent installed and logged in, for example `claude`, and `git`. See the [install guide](https://natamux.github.io/docs/getting-started/install/).
