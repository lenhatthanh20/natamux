This version shows Markdown files rendered in the editor, makes the app and the daemon faster with less memory, and lets the default Review stage read the reports of earlier stages. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Desktop app

- A Markdown file (`.md`) in the editor tab has **Source | Rendered** in its header. **Rendered** shows the file formatted, with your unsaved edits; cursor, scroll and undo stay when you switch back. It opens on Source again after you close it. See [Files of the worktree](https://natamux.github.io/docs/guides/dashboard/#files-of-the-worktree).

## Performance

- The board and the command palette draw only the rows on screen. A board frame takes about 14 ms instead of 62 ms, and the app uses about 160 MB instead of 190 MB.
- The daemon shows the task list at start without waiting for your login shell's PATH. Only starting a program waits for it.
- Many agents that report at once are handled faster: with 30 agents, the slowest hooks take about 8 ms instead of 20 to 40 ms.
- A busy daemon uses about 540 MB instead of 720 MB.
- A terminal keeps less history: about 5,200 lines above the screen at 80 columns, was about 7,800. The limit is still about 10 MB for each terminal. See [Find in the terminal](https://natamux.github.io/docs/guides/terminal/#find-in-the-terminal).

## Stages

- The default **Review** stage prompt reads `spec.md` and the other reports that earlier stages wrote, not a `test-spec.md` that the default workflow never writes. A prompt saved in a project's `.natamux.json` keeps its text. See [The review agent](https://natamux.github.io/docs/concepts/review-loop/#the-review-agent).

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
