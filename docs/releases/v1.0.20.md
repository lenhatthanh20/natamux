This version keeps a task waiting while the agent really waits for you, tells you when an agent finished its turn, and shows the release notes after an update. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Desktop app

- After an update, a **What's new** dialog shows the notes of the new version once. **What's New** in the menu, the command palette and Settings opens it again.
- A turn that ends on a question, also a question followed by a list of options, keeps the task in **Needs input** until you answer.
- A turn that ends with a report notifies **Finished its turn at <stage>**. The task is **Idle**, not red, and the Dock counts it until you open the task.
- `natamux ask` keeps the task waiting for your answer, also when the agent goes on with other tools or the ask first needed a permission.
- A permission you deny no longer leaves the task in **Needs input** after the agent ends its turn.
- A maximized task opens on the terminal you looked at last.
- **Idle** shows as a speech bubble instead of three dots.
- The **Agent** card of **Start a task** no longer lists every stage of a full flow.

## Fixes

- Fix: a task went **Idle** right after the agent ran `natamux ask`, with no notification.
- Fix: the cursor filled almost the whole height of a text box.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
