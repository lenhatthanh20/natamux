Natamux links pull requests that the agent opens itself, starts new tasks from the default branch, finds skills that only your main checkout has, and has a new icon. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Pull requests

- A pull request that the agent or you open another way, such as with `gh pr create`, is now linked to the task, as if **Create pull request** had opened it. Its checks show on the task. Natamux looks for it when the agent stops, on each status check, and on **Check now**. A closed pull request is not linked. See [Pull requests](https://natamux.github.io/docs/guides/github/#pull-requests).

## Workspaces

- A new task starts from the default branch of the repository, not from the branch your main checkout is on. The default branch is `origin/HEAD`, then `main`, then `master`, then the checkout's branch. See [Base branch](https://natamux.github.io/docs/concepts/workspaces/#base-branch).
- Any base branch, picked or default, is fetched first. When your local branch is behind its remote, the task starts from the remote copy. Local commits that are not pushed still win, and your local branches do not change.
- The branch pickers start on the default branch and label it **(default)**.

## Skills

- Fix: a stage could say that a skill was not found for Claude Code, while **Insert skill** offered it. This happened for a plugin turned on only in `.claude/settings.local.json`, or a project skill that is not committed, since a new worktree has only committed files. Now Natamux also looks in your main checkout and gives the agent the path of the skill's `SKILL.md`. See [Skills](https://natamux.github.io/docs/agents/claude-code/#skills).

## App

- Natamux has a new icon: an N made of three lanes, with a cursor.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
