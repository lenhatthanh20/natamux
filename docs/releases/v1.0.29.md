This version shows History at full width, lets you copy from more places, and makes rollback fast in a large worktree. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## History

- The **History** icon on the rail, key `3` and **Show History** close the side panel and show the git graph over the terminals at full width, with the author, hash and age columns. Click the **History** icon again, click **Terminals** or press `Esc` to go back to the terminals. The side panel has no History view any more. See [Changes and History](https://natamux.github.io/docs/guides/changes-and-history/).

## Copy

- A right-click on the text of the editor tab or of a diff opens **Cut**, **Copy**, **Paste** and **Select All**. Cut and Paste are off for text you cannot edit.
- In rendered Markdown, such as the **Docs** view and the release notes, `Mod+C` copies the selected text, and a right-click opens **Copy** and **Select All**.
- The row menu of the **Files** tab and of the **Changes** list has **Copy Path** and **Copy Relative Path**.

## Fixes

- Fix: rolling back files in **Changes** took seconds in a large worktree, even for one file. The Undo snapshot now reads only the files you picked.
- Fix: in **Changes**, the buttons of the comment box, the commit box and the **Push** row did not line up, and a label was cut in a narrow panel. They now line up and wrap.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
