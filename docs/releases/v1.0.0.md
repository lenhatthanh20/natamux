Natamux is now a native app: the desktop app, the daemon and the `natamux` command are written in Rust. It keeps the same data folder, so the same tasks and sign-in stay. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Native app

- The desktop app, the daemon and the `natamux` and `nmx` commands are Rust programs. The app draws its own window; the daemon still serves the dashboard to your browser. See [Desktop app](https://natamux.github.io/docs/guides/desktop-app/).
- The app uses the same data folder as the version before, so it opens with your tasks, worktrees, settings and daemon token.
- The daemon starts on port 4317, or on another free port when 4317 is taken. The `natamux` command in a task terminal finds it.
- The app checks the signature of a release with the same release key as before, and installs nothing that fails the check. See [Updates](https://natamux.github.io/docs/guides/desktop-app/#updates).
- The Docs tab uses the app's text sizes for markdown and for its file list.
- The Docker image `natamux-daemon` runs the Rust daemon. See [Self-host with Docker](https://natamux.github.io/docs/guides/self-host-docker/).
- On Debian and Ubuntu the package is still `natamux`, so `apt install` replaces the old version. The app is `/opt/Natamux/natamux-app`; the `natamux-desktop` command is gone.

## Usage

- Each task shows how many tokens its agents used and an estimated cost in USD: a **Usage** section in the task's **Details** tab, a line such as `$0.42 est. · 610K tokens` under each stage card, and a **Cost** column in the task table. The cost is an estimate at API list prices. Cursor does not report usage. See [Usage](https://natamux.github.io/docs/guides/dashboard/#usage).

## Performance

- Output in one terminal draws only that terminal. The sidebar, the task list, the details panel and the other panes draw again only when their own data changes.
- A window without focus stops the age clock of the sidebar and the 60-second checks of the open task. When the window has focus again, it reads once what it skipped. Changes the daemon sends are still read in the background.
- The open task reads its git state, its events, its stage files and its settings at most once a second. Many changes in a row make one read, the last change is never lost, and the screen draws again only when the result differs.
- The sidebar lays out only the rows on screen. The time labels of the sidebar, the task list and the details panel draw again only when one of them changes.
- In the daemon, a shell that prints a lot no longer holds up the other shells, and a terminal snapshot is written with fewer copies.

## Fixes

- A click on the sidebar or details toggle in the status bar could do nothing. Now every click shows or hides the panel.
- While Claude Code worked in Terminal 1, the sidebar row and the pane header showed a plain `zsh` terminal until the agent's turn ended. Now they show the agent while it prints.
- When the agent of a stage with **End the agent and close its terminal** ended the stage itself (`natamux done` or `natamux stage back`), its terminal closed before the agent saw the answer. Now the terminal closes when the agent ends its turn, at most 60 seconds later. See [End a stage's terminal](https://natamux.github.io/docs/concepts/stages/#end-a-stages-terminal).
- In the dashboard, a terminal you ended with `exit` could leave the screen at once. Now it keeps its last screen and **Open a new terminal**.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
