The **Start a task** dialog now shows which fields make the task's context. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Start a task

- The dialog has two groups. **Context** holds **Title**, **Context from**, **Notes** or **Reference**, and **Attachments**. **Workspace and agent** holds **Project**, **Branch from** and **Agent**.
- A line under **Context** says what the agent reads for the source you pick.
- **Notes** is taller and suggests what to write: what to change and why, where to look, and how to tell it is done.
- **Reference** has a label and a hint under it, such as the issue or ticket to read.
- **Attachments** says the files are part of the task's context.

See [Add a task](https://natamux.github.io/docs/getting-started/quick-start/#2-add-a-task).

## Before you open it

This release is **not signed** with an Apple certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
