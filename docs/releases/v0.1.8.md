Run a hard stage as a Claude Code workflow, and see which fields of **Start a task** make the task's context. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Run a stage as a workflow

- A stage can run as a Claude Code **workflow**: the work is split across several sub-agents, and the result is checked before the stage ends. It is more accurate, but it uses many more tokens.
- In **Project settings**, an agent stage has **Tasks can run it as a workflow** (`"workflow": true` in `.natamux.json`). The default pipeline offers it on **Plan** and **Implement**.
- On a task, the stage card in **Progress** has **Run with a workflow**, off by default. Tick it before the stage starts. A change while the stage runs counts the next time it starts.
- Only Claude Code runs workflows. For other agents the box cannot be ticked.
- While the workflow works, the stage stays running. A stage that ran as a workflow shows a **Workflow** label.
- From the CLI: `natamux stage workflow <task> on --stage implement`.

See [Run a stage as a workflow](https://natamux.github.io/docs/concepts/stages/#run-a-stage-as-a-workflow).

## Start a task

- The dialog has two groups. **Context** holds **Title**, **Context from**, **Notes** or **Reference**, and **Attachments**. **Workspace and agent** holds **Project**, **Branch from** and **Agent**.
- A line under **Context** says what the agent reads for the source you pick.
- **Notes** is taller and suggests what to write: what to change and why, where to look, and how to tell it is done.
- **Reference** has a label and a hint under it, such as the issue or ticket to read.
- **Attachments** says the files are part of the task's context.

See [Add a task](https://natamux.github.io/docs/getting-started/quick-start/#2-add-a-task).

## Before you open it

This release is **not signed** with an Apple certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
