Click **Resume** to start an agent again after a restart, shells of a finished task say why they ended, and the keyboard goes to the agent when you switch tasks. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Terminal

- When a task is done or cancelled, each pane keeps its last screen, dimmed, with no cursor, and takes no keys. You can still scroll, select, copy and find in it. A bar at the bottom says **Task done.** or **Task cancelled.**
- Click **Open a new shell** on that bar to open a plain shell in the task's workspace. It does not start the agent.
- After a daemon restart, the pane shows **The shell ended.** with **Open a new shell** at the bottom.
- When you switch to another task's workspace, the keyboard goes to its first agent shell, so you can type to the agent at once. A shell you pick with **Jump to a workspace** gets the keyboard instead.

See [Shells](https://natamux.github.io/docs/guides/terminal/#shells).

## Dashboard

- The sidebar and the details panel start at the same width, 320 px. A width you set by dragging stays.

## Fixes

- Fix: after you quit and opened the app again, **Resume** on a task that waits for you moved it to running, but no agent ran in its terminal. Now **Resume** starts the agent again in the stage's terminal. Claude Code goes on with the same conversation; other agents start again with the stage prompt. See [Type to the agent](https://natamux.github.io/docs/guides/terminal/#type-to-the-agent).
- Fix: in the desktop app, the first click on a terminal from another app only brought the window to the front, and a second click was needed to type. Now one click does both.

## Before you open it

This release is **not signed** with an Apple certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
