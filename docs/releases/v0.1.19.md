Natamux can skip a stage you mark ahead, opens a GitHub issue only when you ask, sends a failed CI run to the agent again, and starts and runs faster. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Stages

- To skip a stage before the task gets there, click **Skip** on its card in **Progress**. The card then says **Will be skipped**, and the task skips the stage when it reaches it. **Don't skip** takes the mark off. See [Skip a stage](https://natamux.github.io/docs/concepts/stages/#skip-a-stage).
- Fix: when **Check on CI** found a failed run, the fix prompt could stay in the agent's input without being sent, because text in the run's log ended the paste early. Now the prompt is sent at once. See [Check a stage on CI](https://natamux.github.io/docs/concepts/stages/#check-a-stage-on-ci).
- A stage that CI sent back has a short card: **Sent back by CI N×**. Point at it to see the failed runs. The task history says **Sent back by CI**.

## Issues

- Natamux no longer opens a GitHub issue for each task by itself. It opens one only when you click **Create issue** in the task's **Progress** view. Projects whose `.natamux.json` sets `tracker.createIssue` keep their choice.
- **Project settings** has a new **Issues** tab to choose when Natamux opens an issue. **Never** also hides the **Create issue** button. See [The Issues tab](https://natamux.github.io/docs/guides/project-settings/#the-issues-tab).

## Speed

- The desktop window opens at once and shows a loading page while Natamux starts.
- Agent hooks and the task list answer faster. Natamux keeps tasks in memory and notices task files you edit outside it.
- The dashboard gets changes as they happen instead of asking every few seconds.
- Pull requests are checked only while a dashboard is open. A merge shows when you open the dashboard again.
- Line counts of edits that no agent, shell or commit made can take up to 5 minutes to show.

## Terminal

- Fix: every terminal pane showed a thin white line on the left of the scrollbar. It is gone.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
