This version adds an offline mode, a page for security reviews and an SBOM file for each platform, and fixes the start on a Windows with no Visual C++ runtime. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Offline mode

- `NATAMUX_OFFLINE=1`, or `"offline": true` in `settings.json`, turns off every network call that Natamux makes by itself: no update check, no `gh`, and no `git fetch`, `pull`, `push` or `clone`. Local git work is unchanged. An administrator can turn it on for every user with a settings file of the machine. It does not limit coding agents or what you type in a terminal. See [Offline mode](https://natamux.github.io/docs/help/security-review/#offline-mode).

## Security review

- A new page, [For a security review](https://natamux.github.io/docs/help/security-review/), lists every connection Natamux makes, what offline mode turns off, what a release is built from and how the dependencies are controlled.
- Each release has one SBOM file per platform, in CycloneDX 1.5 JSON: `Natamux-mac-arm64.cdx.json`, `Natamux-mac-x64.cdx.json`, `Natamux-win-x64.cdx.json` and `Natamux-linux-x64.cdx.json`. `SHA256SUMS.txt` lists them, so the release signature covers them.
- Natamux depends on 107 fewer third-party crates (630, before 737). The code of the UI library for the system credential store and for a GitHub token is no longer built into the app. Natamux never used it.

## Fixes

- Windows: the app did not start after install on a Windows with no Microsoft Visual C++ runtime, and Windows said **VCRUNTIME140.dll was not found**. The runtime is now built into the app. See [Troubleshooting](https://natamux.github.io/docs/help/troubleshooting/#windows-says-vcruntime140dll-was-not-found).
- The pipeline editor said that a release stage "Opens the pull request by itself". Natamux never opens a pull request by itself. The label is now "Opens the pull request when you click", and the approval box of a release stage is on and locked.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
