Projects must now be approved before Natamux runs their commands, and the agents of each task get their own token that reaches only that task. In the desktop app, each file you open gets its own tab, the Projects dialog has **Browse…** buttons, and the Dock icon shows how many tasks need you. The app starts, switches tasks and opens diffs faster, and token usage counts each turn for the right stage. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Security

- A project's commands run only after you approve them: a stage `check`, a stage `command`, a path condition `when.command`, the words of a stage `args`, and the setup script (`.natamux-setup`, `.natamux-setup.ps1`). Natamux asks again after each change. A project with none of them needs no approval.
- In the desktop app, a dialog lists every command word for word after you add a project, and in **Start a task** for a project that is not approved. Until you approve, the project settings show a **Review commands** row. A save of the settings approves the commands you saved. Without the app, use `natamux repo trust`. See [Approve the project's commands](https://natamux.github.io/docs/guides/project-settings/#approve-the-projects-commands).
- While a project is not approved, a stage with a `check` or a `command` fails with **Repo commands are not approved. Review them in the project settings, then retry.** The setup script does not run, and agents start without auto mode, without their trust of the folder and without stage `args`.
- Projects you added before this version were approved as they were at the first start.
- Each task's terminals get their own `NATAMUX_TOKEN`. It works only for that task, its subtasks and a few reads. So `natamux done`, `stage back`, `ask` and the other agent commands work as before, but a gate command such as `stage approve` typed in a task terminal is refused: run it outside the task.
- The daemon answers only to `127.0.0.1`, `localhost` and `::1` (add more with `NATAMUX_ALLOWED_HOSTS`), and checks the `Origin` of its sockets. Links in a terminal open only `http`, `https` and `mailto`. The data folder is readable only by you. See [Security and privacy](https://natamux.github.io/docs/help/security-and-privacy/).

## Files

- In the desktop app, each file you open from the **Files** view gets its own tab above the editor, in the order you opened them. Opening a file that is already open shows its tab. Tabs that do not fit wrap to the next row, and two files with the same name show their folder.
- A dot on a tab means an edit that is not saved. The **x** on a tab asks first when there is one. `Mod+W` closes the shown file and keeps its edit. See [Files of the worktree](https://natamux.github.io/docs/guides/dashboard/#files-of-the-worktree).

## Projects

- In the desktop app, the Projects dialog has a **Browse…** button next to **Folder** and next to **Worktree folder**. It opens the system folder picker and puts the folder you pick in the field. See [Add a project](https://natamux.github.io/docs/getting-started/quick-start/#add-a-project).

## Notifications

- On macOS, the Dock icon now shows how many tasks need you. Turn on **Notify me** and allow notifications to see the count. If you allowed notifications before, the count shows after a restart, with no new prompt. See [Notifications and the Dock](https://natamux.github.io/docs/guides/desktop-app/#notifications-and-the-dock).

## Speed

- The desktop app opens its window at once and fills it when the daemon is ready. A task you showed in the last 10 shows again at once.
- Task changes no longer read the full task list each time. A task file you edit by hand shows within 60 seconds.
- Diffs open faster, and the next file of the **Changes** tab is read ahead.
- On the board, the Done and Cancelled columns show their 50 newest cards; **Show 50 more** shows more.
- A terminal that fell far behind its output comes back with its last 1,000 lines of history, so it shows again sooner. See [Terminal](https://natamux.github.io/docs/guides/terminal/).

## Usage

- The agent turn that runs `natamux done` or sends a stage back now counts for that stage, not for **No stage** or the next stage.
- The last model call of a turn, and the usage of a terminal that ends with no hook after it, are no longer lost.
- Tasks from before this version keep their numbers.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
