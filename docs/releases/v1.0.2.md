In the desktop app, **Start a task** can now start from any branch of `origin`, also one you never fetched, and the top of a project's Settings page is cleaner. This release also fixes three bugs. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Desktop app

- In **Start a task**, **Branch from** has a folded **Remote branches** group. It lists the branches of `origin` that have no local branch of the same name, also ones you never fetched. Pick `origin/<branch>` to start the task from it: Natamux fetches only that branch and makes no local branch for it. Without a network, a copy fetched earlier is used. When `origin` has no such branch, the workspace fails with "There is no branch <branch> on origin". See [Base branch](https://natamux.github.io/docs/concepts/workspaces/#base-branch).
- The header of a project's Settings page reads "Projects / <name>", with the close button at the right. **Stages**, **Issues** and **JSON** are tabs in a row under the header, and they stay on screen while the page scrolls. The path of `.natamux.json` is now in the bottom bar, next to **Reset to default**, **Import** and **Export**. Hover it to see the full path.
- With **Blur names** on, a project's names, titles and labels show as soft blurred bars as wide as the text, as in the web dashboard, and not as dots. Tooltips still show dots.

## Fixes

- In the **Progress** view, a long line under **Show evidence** ran past the right edge of the stage card. Now it wraps inside the card.
- When a stage that ends its terminal ran again in the same terminal within 20 minutes, the terminal could show "The terminal ended." while the new agent was working. Now it shows the new terminal.
- With git-lfs installed by Homebrew, making a task's worktree could fail with `git-lfs: command not found`, and the next try said the branch already exists. Natamux's own `git` and `gh` commands now use the `PATH` of your login shell.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
