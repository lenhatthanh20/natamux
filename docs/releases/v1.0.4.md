You can now leave review comments on the lines of a task's diff and send them to the agent in one go, idle agents pause to free memory, the desktop app shows the plan limits of the agents and has more themes, and deleting a task now deletes its branch. This release also fixes two bugs. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Changes

- Comment on a line of a task's diff, or on a whole file, in the desktop app and the web dashboard. A comment is saved as a draft under its line and in the **Comments** list, and stays on its code when the agent edits the file. **Send N comments** (`Mod+Alt+Enter`) writes every open comment to `.natamux-task/review-comments.md` and pastes one prompt into Terminal 1. Click **Resolve** when a comment is fixed. See [Comment for the agent](https://natamux.github.io/docs/guides/changes-and-history/#comment-for-the-agent).

## Agents

- An agent that ended its turn and waited 30 minutes, with no window that shows its terminal, now pauses: Natamux ends its terminal and keeps its conversation. Open the task, show the pane or type in it, and the agent starts again on the same conversation. To change the minutes, or to turn it off with `0`, use **Pause idle agents after (min)** on the **Stages** tab of a project's settings, or `agents.pauseIdleAfterMinutes` in `.natamux.json`. See [An idle agent pauses](https://natamux.github.io/docs/guides/terminal/#an-idle-agent-pauses).

## Desktop app

- The status bar shows the agent nearest its plan limit, such as **Claude 84% · 5h**. Click it for each agent's windows and when they reset. A toast says when a window passes 80%, and **Start a task** shows the share next to each agent. Only Claude Code (Pro or Max) and Codex (ChatGPT plan) tell their limits. See [Plan limits](https://natamux.github.io/docs/guides/dashboard/#plan-limits).
- Nine more theme families: Ayu, Catppuccin, Dracula, GitHub, Gruvbox, Nord, Rosé Pine, Solarized and Tokyo Night. Pick one under **Light theme** and **Dark theme** in **Settings → Appearance**. See [Settings](https://natamux.github.io/docs/guides/dashboard/#settings).

## Tasks

- Deleting a task now also deletes its branch, also when the branch has commits that are not merged. Those commits are lost. A task whose worktree has changes that are not committed is still not deleted. For a task that used **Check on CI**, its `natamux-ci/` branch on GitHub goes too; before, only a done or cancelled task lost it. Only the branch of the pull request stays on GitHub, with the pull request.

## Fixes

- Since v1.0.0 the desktop app showed no macOS notifications, played no sound and showed no count on the Dock icon. Now a task that needs you or is done while the app is in the back shows a notification with the task title, the stage and the project, and plays your alert sound once. Click it to open the task. The Dock icon shows how many tasks need you. See [Notifications and the Dock](https://natamux.github.io/docs/guides/desktop-app/#notifications-and-the-dock).
- In a narrow desktop app window, where the sidebar is a drawer, a click on a task in the drawer only closed the drawer. Now it opens the task.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
