In the desktop app, text boxes now take the keys of a text field in a web page, and the History view fits its panel and can show the graph at full width. Two fixes: the side-by-side diff scrolls to the end again, and the **Create issue** button no longer stretches over its row. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Desktop app

- Text boxes take the keys of a text field in a web page: move or delete by word and to the start or end of the line in every box, and `↑`, `↓`, `Page Up`, `Page Down` and the keys to the start or end of the text in boxes of many lines, such as **Notes**, the commit box and the comment box. Long lines wrap at the edge of the box, also in **Notes** of **Start a task**. See [Text boxes](https://natamux.github.io/docs/reference/shortcuts/#text-boxes).
- The rows of **History** in the side panel fit the panel: a long message is cut short, the age always shows, and the whole message is in a tooltip. The new **Show in main** button closes the panel and shows the graph over the terminals at full width, with author, hash and age. **Terminals** (or `Esc`) goes back. See [History tab](https://natamux.github.io/docs/guides/changes-and-history/#history-tab).

## Fixes

- The side-by-side diff could not scroll to the end of a file when one side had many changed lines at the end. Now both sides scroll to the last line.
- In the details panel, the **Create issue** button stretched over the whole row. Now it is as wide as its label, and the row is as tall as the rows around it.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
