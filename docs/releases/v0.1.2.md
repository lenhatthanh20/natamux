The desktop app now updates itself. This is the last version you install by hand.

Guide: https://natamux.github.io/docs/

## Changes

- **Updates.** The app checks GitHub for a new release about 30 seconds after it starts and every 6 hours. It downloads the new version in the background, checks it against `SHA256SUMS.txt`, and installs it when you click **Restart Now**. On macOS a ready update also goes in when you quit. See [Updates](https://natamux.github.io/docs/guides/desktop-app/#updates).
- **Check for Updates…** and **Check for Updates Automatically** in the app menu (macOS) or the **Help** menu (Linux).
- The `.tar.gz` build and a macOS app run straight from the disk image cannot replace themselves. They tell you about a new version and open the release page.
- The check sends no data about you or your tasks. See [PRIVACY.md](https://github.com/lenhatthanh20/natamux/blob/main/PRIVACY.md).

## Download

| System | File |
|---|---|
| macOS, Apple silicon (M1 and later) | `Natamux-mac-arm64.dmg` |
| macOS, Intel | `Natamux-mac-x64.dmg` |
| Linux, any distribution | `Natamux-linux-x86_64.AppImage` |
| Debian, Ubuntu | `Natamux-linux-amd64.deb` |
| Linux, no install | `Natamux-linux-x64.tar.gz` |

`SHA256SUMS.txt` lists the checksum of every file.

## Before you open it

This release is **not signed** with an Apple certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Ubuntu 24.04 and later, AppImage:** the system can block Chromium's sandbox. Install the `.deb` instead, or start the AppImage with `--no-sandbox`.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
