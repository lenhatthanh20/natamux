Natamux keeps Shell 1 open for the whole task, takes task titles of up to 400 characters, and says **Create PR** on the button that opens a pull request. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Stages

- A stage in Shell 1 no longer closes it when it is done. Shell 1 keeps the task's agent and its session, so the next stage gets its prompt in the same session. In the stage settings, a stage in Shell 1 shows "This stage runs in Shell 1, which cannot be closed." in place of **End the agent and close its shell when the stage is done**. A `.natamux.json` with `"endShell": true` on a Shell 1 stage still loads; the flag is ignored there. See [End a stage's shell](https://natamux.github.io/docs/concepts/stages/#end-a-stages-shell).

## Terminal

- Fix: a shell that a stage closed while you looked at another task came back as an empty plain shell when you opened the task again. It now stays closed.
- Fix: a new shell, a closed shell, or a banner or panel that changed a terminal's size showed the shell redrawing. The pane is now hidden while its size changes, and fades in after the shell has redrawn.

## Dashboard

- The button that opens a new pull request says **Create PR** in the workspace header, the phone **Git actions** menu, the banner of a finished task, the wrap-up and the toast after a push. Before, a narrow window showed **Open PR**, the same text as the link to an existing pull request. See [Push and open a pull request](https://natamux.github.io/docs/guides/changes-and-history/#push-and-open-a-pull-request).

## Tasks

- A task title may have up to 400 characters, up from 200. See [Task fields](https://natamux.github.io/docs/concepts/tasks/#task-fields).
- Fix: when the daemon refused a field, **Start a task** said only "The daemon answered with status 400." The message now names the field and the reason, such as `title: Too big: expected string to have <=400 characters`.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
