Natamux lets each project choose its own worktree folder, never closes an agent while its task runs, and keeps the output of Copilot CLI in the terminal history. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Projects

- When you add a project, **Worktree folder** sets where the worktrees of its tasks go. It starts with the daemon's worktree folder, and Natamux makes the folder if it is not there. Workspaces made before keep their place. See [Repositories](https://natamux.github.io/docs/guides/dashboard/#repositories).

## Stages

- A stage with its own agent or arguments now runs in a shell of its own: Shell 6 for the first such stage of the pipeline, Shell 7 for the next, and so on. Shell 1 keeps the task's agent and its session for the whole task. When such a stage runs again, for example after a send back, its prompt goes into the agent in its shell. See [Choose a model](https://natamux.github.io/docs/concepts/stages/#choose-a-model).

## Agents

- Natamux starts Copilot CLI with `--no-alt-screen`, so its output goes into the terminal history like the other agents, and the light line at the right edge of the terminal is gone. To get the full screen back, set `NATAMUX_COPILOT_ARGS="--alt-screen on"`. See [What Natamux runs](https://natamux.github.io/docs/agents/copilot/#what-natamux-runs).

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
