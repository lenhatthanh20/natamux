This version adds a revert arrow with Undo to each change in the diff, find, go to line and outline tools to the editor and the diff, and a prompt-first stage sheet. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Desktop app

- In the **Changes** diff, the change at the cursor shows a revert arrow. A click puts the last commit's lines of that change back into the file. The toast has **Undo**, and `Mod+Z` in the diff undoes the newest revert.
- The editor and the diff get IDE tools: a find bar (`Mod+F`, with match case and regex), **Go to line** (`Ctrl+G`), **Go to symbol** (`Mod+Shift+O`), **Ignore whitespace** and **Show whitespace** toggles, a **Comment** button next to the revert arrow, `Mod+'` to fold or open a change in the inline diff, and new editor keys (more cursors, move, duplicate or delete a line, toggle comments). The editor tab gets a wrap toggle, and **Settings → General → Editor** gets **Clean on save** (off by default).
- The stage sheet (**Settings** → a project → **Stages** → a stage) puts the prompt first: the prompt fills the left side, the settings sit in folding groups on the right, and arrows in the header move to the stage before or after. The switch is now **End the agent when done**.

## Site

- The new [Use cases guide](https://natamux.github.io/docs/guides/use-cases/) shows workflows for simple projects, solo work, teams and larger organizations. Find it beside the homepage install action or browse the four scenario groups in the workflow section.
- The homepage offers a one-line install command for each system. All files are on the new Download page.

## Fixes

- Bundled SQLite could expose memory when a database and its WAL file had different page sizes. Update SQLite to 3.54.1.
- Cursor and Copilot stages return to running when a tool completion ends a permission or terminal-bell wait, including after a restart. Explicit questions still wait for an answer.
- Undo in the editor tab no longer brings back old text after the file was read again from disk.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
