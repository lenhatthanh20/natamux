Change the stages of a project on a screen, use skills in stage prompts with any agent, and see the last row of the terminal again. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Project settings: Stages

- **Settings** in the menu of a project now opens a **Stages** tab, next to the **JSON** tab. You change the pipeline without writing JSON.
- **Add stage** picks from a catalog of common steps (Research, UX design, Security review, End-to-end tests, Manual QA and more), or makes a **Custom stage**.
- Turn a stage off with its switch. It stays in `.natamux.json` with `"enabled": false`, and new tasks do not get it.
- Drag a stage, or press `Alt+ArrowUp` and `Alt+ArrowDown`. **Run alongside the stage above** runs two stages side by side.
- **Wait for my approval** shows whether the value is the default. **Prompt** shows the default prompt, and you can change it.
- A flow chart on top shows the pipeline while you edit it.
- **Save** changes only `stages` and keeps the rest of the file. When the stages equal the default, the file has no `stages`. If the file changed on disk, you can **Reload** or **Overwrite**.

See [Project settings](https://natamux.github.io/docs/guides/dashboard/#project-settings).

## Skills in prompts

- **Insert skill** puts `{skill:<name>}` in a prompt. Natamux fills it for the agent of the task: `/name` for Claude Code and Copilot CLI, `$name` for Codex, and the path of the skill file for Gemini CLI, Cursor CLI and any other agent. When no skill is found, the stage card says so and the stage still starts.
- Claude Code plugin skills are found too (`<plugin>:<skill>`).
- Fix: the `skill` context source sent `/<skill> <ref>` to every agent, which only Claude Code understands. It now follows the same rules.

See [Skills in a prompt](https://natamux.github.io/docs/concepts/stages/#skills-in-a-prompt).

## Fixes

- **The last row of the terminal was cut off.** The terminal took a few more rows and columns than its pane could show, so the bottom row, such as the status line of Claude Code, was hidden under the edge of the pane. The terminal now fits its pane.

## Before you open it

This release is **not signed** with an Apple certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
