Natamux starts sooner, holds less GPU memory and starts far fewer programs in the background. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Speed

- The app no longer waits for your login shell before it starts. The dashboard shows your tasks at once; changes, branches, terminals and agents start when the shell's `PATH` is read. On a Mac just turned on, that wait was about 4 s.
- A terminal hidden for 10 s gives back its GPU memory. It takes it again when you show it.
- The daemon reads the list of processes once every 2 s for all panes, and keeps the git answers of Changes and History for 5 s, so it starts far fewer programs. **Refresh** (`Shift+R`) still reads at once. Changes made outside Natamux can take a few seconds more to show.
- The dashboard asks for the shells of a task once, not once per view. When time passes, only the labels that show it redraw, not the whole dashboard.
- With many tasks, a burst of updates redraws the list once, and only the rows that changed.
- The Agents view loads its terminal code ahead, so it opens faster the first time.

## Tasks and terminals

- **Start a task** can take its context from any agent skill: pick **An agent skill** in **Context from**, then the skill and the record reference.
- After a restart, the agent of a stage in review starts again too, so its terminal is not a bare shell.
- Terminal panes without the focus are no longer dimmed. The focused pane keeps its outline, and an ended shell stays dimmed.

The Intel Mac and Linux builds are paused. The last release with them is [v0.1.2](https://github.com/lenhatthanh20/natamux/releases/tag/v0.1.2). On those systems **Check for Updates…** finds this version but no file for it, and shows an error. Keep using v0.1.2 there.

## Before you open it

This release is **not signed** with an Apple certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
