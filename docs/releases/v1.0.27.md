This version starts eleven more agent CLIs, shows the preparing spinner as soon as a new task opens, and lets **Delete task** go at once. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Agents

- Natamux starts 16 coding agents, was 5. OpenCode, Qwen Code and Factory Droid have hooks and report each state. See [OpenCode](https://natamux.github.io/docs/agents/opencode/), [Qwen Code](https://natamux.github.io/docs/agents/qwen/) and [Factory Droid](https://natamux.github.io/docs/agents/droid/).
- Amp, Kimi, Goose, Aider, Crush, Cline, Kiro and Muse Code start too. Natamux follows them by their terminal, and pastes the first prompt into the terminal once the agent's first screen settles. See [More terminal agents](https://natamux.github.io/docs/agents/more-agents/) and [Agents](https://natamux.github.io/docs/agents/).

## Tasks

- A new task shows **Preparing workspace** as soon as it opens. Before, it could first show the view of a task with no workspace, with its buttons. See [Quick start](https://natamux.github.io/docs/getting-started/quick-start/).
- The **Delete task** button works at once, while the app still reads the worktree's uncommitted changes, which is slow in a big worktree. A delete confirmed before the read ends does not discard those changes: it fails and the task comes back with a message. See [Sidebar](https://natamux.github.io/docs/guides/dashboard/#sidebar).
- Fix: from 1000 files to commit, the **Changes** badge of the details rail wrapped onto two lines. It now shows **1k+**, and its tooltip shows the exact count.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
