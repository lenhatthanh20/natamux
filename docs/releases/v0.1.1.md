A small update to [v0.1.0](https://github.com/lenhatthanh20/natamux/releases/tag/v0.1.0).

Guide: https://lenhatthanh20.github.io/natamux/docs/

## Changes

- The macOS app is now `Natamux.app` (it was `natamux.app`).
- Download files no longer carry the version in their name, so `releases/latest/download/<file>` links always point to the newest build.
- `natamux task show` without an id shows the task of the terminal you run it in.
- `natamux agent start` on a task with no workspace makes the workspace first (`--base` picks the branch). The dashboard and the CLI now start the agent you picked, not the task's default one.
- The sign-in page names the real place of the token: `NATAMUX_TOKEN` of the daemon.

## Download

| System | File |
|---|---|
| macOS, Apple silicon (M1 and later) | `Natamux-mac-arm64.dmg` |
| macOS, Intel | `Natamux-mac-x64.dmg` |
| Linux, any distribution | `Natamux-linux-x86_64.AppImage` |
| Debian, Ubuntu | `Natamux-linux-amd64.deb` |
| Linux, no install | `Natamux-linux-x64.tar.gz` |

`SHA256SUMS.txt` lists the checksum of every file.

## Before you open it

This release is **not signed** with an Apple certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Ubuntu 24.04 and later, AppImage:** the system can block Chromium's sandbox. Install the `.deb` instead, or start the AppImage with `--no-sandbox`.

See the [install guide](https://lenhatthanh20.github.io/natamux/docs/getting-started/install/).
