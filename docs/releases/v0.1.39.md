You can now roll back changes that are not committed from the Changes tab, and the panes of a task are called terminals. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Changes tab

- **Rollback…** puts files that are not committed back as they are in the last commit. Click it in the header of the file list, pick it in the menu of a file or folder row, or press `Mod+Alt+Z` for the file in the diff. See [Roll back changes](https://natamux.github.io/docs/guides/changes-and-history/#roll-back-changes).
- A dialog lists the files, all checked. A changed or deleted file goes back to the last commit, a new file is deleted, and a file with a conflict cannot be rolled back. Ignored files are never touched.
- The toast **Rolled back N files.** has **Undo**, which brings the files back as they were just before. Only the last rollback of a task can be undone, until the daemon restarts.
- New HTTP routes `POST /tasks/:id/rollback` and `POST /tasks/:id/rollback/undo`. See [HTTP API](https://natamux.github.io/docs/reference/http-api/).

## Dashboard

- The panes of a task are called terminals: **Terminal 1**, **Terminal 2**, **New terminal**, and the sidebar tag T1. "Shell" now means only the shell program. See [Terminals](https://natamux.github.io/docs/guides/terminal/#terminals).

## Fixes

- Fix: when the file list of the Changes tab was narrow, **Commit all** covered the diff. Now it moves to its own line.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
