This version moves Natamux to the MIT license, closes the findings of a security audit, fixes bugs in the terminal, the editor and the diff, and makes the app faster. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## License

- Natamux is now under the MIT license. Releases up to v1.0.27 were GPL-3.0-or-later. Natamux has its own terminal, text input, code, diff and Markdown views, UI parts and themes in place of the GPL crates of Zed. The app looks the same, apart from new icons.

## Security

- A project that has an agent config file, such as `.claude/settings.json`, `.mcp.json`, `.codex/config.toml`, `.codex/hooks.json`, `.cursor/mcp.json` or `.gemini/settings.json`, asks for one new approval after the update. These files hold hooks and MCP servers that an agent runs, so they are now part of what you approve. A setup script that is a link never runs. See [Repo trust](https://natamux.github.io/docs/help/security-and-privacy/#repo-trust).
- The agent token does less: a subtask stays in the project of its parent, and an agent cannot send the events only the daemon sends, nor report a command stage done.
- The text of an imported GitHub issue is marked as data in the prompt, so an agent reads it as text, not as instructions.
- A task has at most 32 terminals.
- The web dashboard is gone; the native app is the only UI. The daemon serves no browser page.

## Fixes

- Fix: in the Changes diff, the Comment and **Revert this change** buttons flickered while the pointer was on them.
- Fix: in the terminal, text you type with an input method kept the wrong widths, and a link that wraps over two rows was two links.
- Fix: the editor tab changed CRLF line ends to LF on save.
- Fix: toggling a comment on a line that starts with a no-break space closed the app.
- Fix: reverting a change lost lines after a lone CR.
- Fix: `^` in find matched only at the start of the file, not at each line.
- Fix: files such as `tsconfig.json` and `flake.lock` had no syntax colours.

## Speed

- The terminal, the text and diff views, and task events do less work per frame. The app uses less memory, and its programs are about 20% smaller.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
