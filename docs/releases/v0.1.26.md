Natamux can end a stage's agent and close its shell when the stage is done, runs Codex and Gemini inline, and calls the waiting state "Needs input". If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Stages

- A context, agent or testing stage can end its agent and close its shell when it is done: check **End the agent and close its shell when the stage is done** in the stage settings, or set `"endShell": true` in `.natamux.json`. A next stage in that shell starts a new agent session. It is off by default. See [End a stage's shell](https://natamux.github.io/docs/concepts/stages/#end-a-stages-shell).
- Fix: a testing stage whose command was running when the daemon stopped stayed running forever. When the daemon starts, it now runs the command again in a new shell.

## Agents

- Codex starts with `--no-alt-screen`, and Gemini runs with `ui.useAlternateBuffer` set to `false`. Both run inline, so their output goes into the terminal history. See [Codex](https://natamux.github.io/docs/agents/codex/#what-natamux-runs) and [Gemini CLI](https://natamux.github.io/docs/agents/gemini/#what-natamux-runs).
- The Claude Code page explains the empty rows that Claude Code can leave under its footer after a turn, and how to avoid them. See [Limits](https://natamux.github.io/docs/agents/claude-code/#limits).

## Dashboard

- The waiting state is now called **Needs input**, so its chip fits the **State** column of the Table view. See [Status icons](https://natamux.github.io/docs/guides/status-icons/).

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
