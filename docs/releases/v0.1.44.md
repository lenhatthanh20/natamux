The app does less work with many terminals open: a terminal that prints draws only itself, and a window in the background stops its clocks and polls. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Performance

- Output in one terminal draws only that terminal. The sidebar, the task list, the details panel and the other panes draw again only when their own data changes.
- A window without focus stops the age clock of the sidebar and the 60-second checks of the open task. When the window has focus again, it reads once what it skipped. Changes the daemon sends are still read in the background.
- The open task reads its git state, its events, its stage files and its settings at most once a second. Many changes in a row make one read, the last change is never lost, and the screen draws again only when the result differs.
- The sidebar lays out only the rows on screen. The time labels of the sidebar, the task list and the details panel draw again only when one of them changes.
- In the daemon, a shell that prints a lot no longer holds up the other shells, and a terminal snapshot is written with fewer copies.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
