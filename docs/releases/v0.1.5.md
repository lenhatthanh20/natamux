A fix for stages that run side by side, and small terminal changes. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Fixes

- **The shell of a parallel stage showed late.** When a task started stages side by side (for example **Implement** and **Test spec**), the second stage's shell was running but did not show until you left the task and came back. It now shows as soon as the stage starts. The shell you type in keeps the keyboard, and a shell you close stays closed.
- **Agents grid:** panes stay in place. A task event no longer moves its pane to the front.
- **Vietnamese typing in Claude Code.** With an input method such as GoTiengViet, EVKey or OpenKey, letters were lost or mixed up. The input method erases a letter and types the accented one; Natamux now sends the two a moment apart, so Claude Code reads them apart.

## Terminal

- The scrollbar is thin, like the rest of the app, and shows search matches.
- **Less memory for finished tasks.** Opening the shell of a done or cancelled task started a shell that kept running after you left. It now ends a minute after no pane shows it, unless a program such as a dev server runs in it.

## Before you open it

This release is **not signed** with an Apple certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
