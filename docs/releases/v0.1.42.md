A new task opens at once while its workspace is made, the status bar shows background jobs, and a running stage keeps its terminal when the settings change. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Dashboard

- A new task answers at once. Natamux makes the worktree and starts the first agent in the background, and the task shows **Preparing workspace** with the current step. A toast says when the workspace is ready or failed. A failure keeps the task, so **Create workspace** can try again. See [Start a task](https://natamux.github.io/docs/getting-started/quick-start/#start-a-task).
- The status bar shows background jobs: workspace changes, the checks of a stage, a wait for CI, and opening or importing GitHub issues. One job shows with a spinner, more as a count. Click it to see each job, its task and how long it has run. See [Background jobs](https://natamux.github.io/docs/guides/dashboard/#background-jobs).

## Stages

- When Spec or Plan runs in its own terminal, an empty Terminal 1 names the terminal that works now, such as **Terminal 5 is working**. See [Terminals and agents](https://natamux.github.io/docs/concepts/stages/#terminals-and-agents).

## Fixes

- A settings change could move a running stage to another terminal, so `natamux done`, turn ends and send backs reached the wrong stage. Now a stage keeps the terminal it started in until it starts again. See [Choose a model](https://natamux.github.io/docs/concepts/stages/#choose-a-model).

## HTTP API

- `GET /jobs` lists the background jobs, and `jobs.changed` says when one starts or ends. See the [HTTP API](https://natamux.github.io/docs/reference/http-api/).

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
