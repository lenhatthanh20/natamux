This version gives new projects a short default pipeline, redesigns Settings and Start a task, and lets a task run without a worktree. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Desktop app

- A new project gets a short default pipeline: Context → Spec → Implement → Review → Release.
- A path of an If branch can hold side-by-side stages, not only single stages.
- **Start a task** has a new card layout and a **Create a worktree** switch. Turn it off to make the task without a worktree.
- **Settings** and **Project settings** have a new layout with inset cards. Agents, stages and branches open in their own sheet. Stages show a **Built-in** or **Custom** tag, and a changed value shows a dot and a Reset button.
- Custom stage marks are brighter.
- The **JSON** tab of Project settings wraps long lines and has a Copy button.
- File icons show in their own colours.
- Quitting the app asks first, so a slipped Mod+Q or close button no longer stops every agent and terminal.
- Maximize is a mode of the task: it shows one terminal at a time, full size, until you click Restore. It stays when you switch tasks or restart the app.
- Files and folders dropped from Finder, Explorer or a file manager onto a terminal type their paths.
- A terminal header names its stage, for example `Self check · Terminal 17`. A notification names the waiting terminal, and a click opens it.
- **Notify me** is on for a new install. A new **Always notify** setting also notifies while the window is in front.
- An agent that ends its turn without a question shows **Idle**, not **Needs input**.
- Stage args and prompts can use `{id}`.
- **Delete task** removes the task at once and deletes it in the background. If the delete fails, the task comes back with an error message.

## Fixes

- Fix: scrollbars in Settings moved with the content, or let content that fits scroll.
- Fix: the flowchart in Project settings scrolled inside the page and cut off branch notes. It now grows with its content.
- Fix: the scrollbar of the **JSON** tab did not run the full height, and text was cut off.
- Fix: the **Title** box of Start a task sat far from its label. It now fills the row after the label.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
