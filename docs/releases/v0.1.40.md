You can now reopen the agent of a finished task and delete all done or cancelled tasks at once. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Dashboard

- **Reopen agent** in the wrap-up of a done or cancelled task starts the agent of Terminal 1 again, on its last conversation, with no new prompt. The task keeps its state. See [When a task is finished](https://natamux.github.io/docs/guides/dashboard/#when-a-task-is-finished).
- New HTTP route `POST /tasks/:id/agent/reopen`. See [HTTP API](https://natamux.github.io/docs/reference/http-api/).
- The Done and Cancelled columns of the board have a trash button: **Delete all done tasks**, **Delete all cancelled tasks**. Natamux asks first and lists the tasks. A task with changes that are not committed is skipped, and one message reports the result. See [Task views](https://natamux.github.io/docs/guides/dashboard/#task-views).
- The Overview card of the Progress view is one row of short figures: **Stages** (as 1/6), **Total** or **Start to finish**, **This stage** and **Sent back**. A tooltip gives the full meaning of each.

## Desktop app

- On macOS 26, the menu items of Natamux have icons, so their titles line up with the system items. On Windows and Linux, **Settings…** has its own group in the **File** menu. See [Menu](https://natamux.github.io/docs/guides/desktop-app/#menu).

## Fixes

- Fix: Copilot CLI printed a warning at start and skipped `.claude/settings.local.json`, the Claude Code hook file Natamux writes in the worktree. Now the file runs `natamux hook claude-code` as a command, which does nothing outside Claude Code, so Copilot shows no warning and reports each event once. See [Copilot](https://natamux.github.io/docs/agents/copilot/#how-hooks-are-added).

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
