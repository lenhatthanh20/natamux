Natamux lets a pipeline split into paths by a condition, and blurs a project's names in the sidebar while you share your screen. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Stages

- A branch splits the pipeline into 2 to 4 paths, each with a condition and its own stages: a file has some text, or a command succeeds. The task takes the first path that holds, and the stages of the other paths never run. The last path can be the **Otherwise** path. Build it with **Add branch** in **Project settings → Stages**; the chart shows it as an **If** node, and the **Progress** view says which path the task took. See [Paths with a condition](https://natamux.github.io/docs/concepts/stages/#paths-with-a-condition).

## Dashboard

- Click the eye next to a project in the sidebar (**Blur names**) to blur the names of the project, its tasks, subtasks, agents and finished workspaces, also in **Pinned**. Task states stay visible. Click it again (**Show names**) to see them. See [Sidebar](https://natamux.github.io/docs/guides/dashboard/#sidebar).

## Desktop app

- Timed update checks are now off by default. Before, they were on by default. If you never changed **Check for Updates Automatically**, the app stops its timed checks after this update and looks for a new version only when you choose **Check for Updates…**. To check every 6 hours again, tick **Check for Updates Automatically**. If you ticked it yourself before, the timed checks stay on. See [Updates](https://natamux.github.io/docs/guides/desktop-app/#updates).

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
