Natamux shows the notice of a task and its actions in the current stage card, and the Account menu can open an issue. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Stages

- The notice of a task that needs input, failed or waits for review is now in the current stage card of the **Progress** view in the details, with its actions: **Answer in terminal**, **Resume**, **Start agent**, **Approve** and **Send back**. In v0.1.33 it was in the workspace header row, where the review notice could draw over the git buttons. See [Control a stage by hand](https://natamux.github.io/docs/concepts/stages/#control-a-stage-by-hand).
- The workspace header shows the state of the task in every state. With the details closed, click **Needs input**, **Failed** or **In review** there to open them at the current stage. See [Needs input or failed](https://natamux.github.io/docs/guides/terminal/#needs-input-or-failed).
- On a phone, the banner under the header stays as it was.

## Dashboard

- **Account → Report an issue** opens a new issue on the Natamux repository on GitHub, in your browser. See [Account menu](https://natamux.github.io/docs/guides/dashboard/#account-menu).

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
