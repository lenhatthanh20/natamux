Natamux can ask the agent about selected lines of a diff, and shows the files of a task's worktree with an editor for one file. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Changes

- Select lines in a diff, then click **Ask agent**, press `Mod+Shift+A`, or pick **Ask agent about the selection** in the right-click menu. The lines go into the comment box, and the agent gets the file, the line range and the code. Lines from the left side of a side-by-side diff are marked **(before the change)**. Over 10,000 characters, only the line numbers are sent. See [Ask about selected lines](https://natamux.github.io/docs/guides/changes-and-history/#ask-about-selected-lines).

## Files

- The details panel has a new **Files** view with the files and folders of the task's worktree. A changed file has the same letter and color as in the **Changes** tab. See [Files of the worktree](https://natamux.github.io/docs/guides/dashboard/#files-of-the-worktree).
- Drag a file or folder onto a terminal of the same task to paste its path there. Natamux does not press Enter.
- Click a file to open it in a tab of the workspace, edit it and press `Mod+S`. An edit that is not saved stays when you switch tabs, files or tasks. When the agent changes the file while you edit it, choose **Reload** or **Keep mine**. A binary file or a file over 1 MB is not shown.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
