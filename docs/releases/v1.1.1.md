This version trusts a project once in Personal mode, shows what agents with background work need from you, and adds settings for IT teams. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Trust

- In Personal mode you trust a project once, like a workspace in an editor: in the app dialog or with `natamux repo trust --approve`. From then on every task of the project is trusted, also after its commands, setup scripts or agent config change.
- Before, a task whose files differed from what you approved, for example after `git pull`, started its agent without auto mode and without folder trust, and nothing told you.
- The app asks **Trust <project>?** once per project: after you add it, before **Start a task**, and in the project settings. A project whose agent config you approved in v1.1.0 needs nothing more; other projects ask once.
- An agent that starts in a folder that is not trusted writes a warning to the task's log.
- Strict mode still asks again for each change, per worktree. A branch cannot leave Strict mode by removing it from its own `.natamux.json`.

See [Repo trust](https://natamux.github.io/docs/help/security-and-privacy/#repo-trust).

## Agents with background work

When an agent ends its turn while background work runs, the task no longer hides what happens next.

- A question the agent asks while background work runs moves the task to **Needs input**. A newer question shows on the card.
- A turn that background work or a scheduled prompt started, not you, marks the task as unread. It rings only with the new setting **Notify when a background result arrives**.
- A turn that leaves only scheduled prompts (`/loop`, cron) counts as finished: "Finished its turn · next: <prompt>".
- The new setting **Flag background work older than** lists hung background work in **Needs you**, with "Waiting for <work> since HH:MM".

Both settings are in **Settings > Notifications**. See [Waiting for background work](https://natamux.github.io/docs/concepts/agents-and-hooks/#waiting-for-background-work).

## For IT and admins

- The settings file of the machine takes `"strict": true` (Strict mode for every user, which the app cannot turn off) and `"updates": false` (no update check or download). See [Settings file of the machine](https://natamux.github.io/docs/help/security-review/#settings-file-of-the-machine).
- A new Windows install keeps its data in `%LOCALAPPDATA%`. An older install keeps `%APPDATA%`.
- The daemon refuses a host that is not this machine unless `NATAMUX_ALLOW_REMOTE_BIND=1`. Strict mode sets `DO_NOT_TRACK` and `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` for agents.
- The install scripts install a chosen release with `NATAMUX_VERSION`, for example `v1.1.1`. See [Install a chosen version](https://natamux.github.io/docs/getting-started/install/#install-a-chosen-version).
- Release files are built clean, after an advisory check, with a build record per system. The SBOM also lists the bundled SQLite and rustc. See [Licensing](https://natamux.github.io/docs/help/licensing/).

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
