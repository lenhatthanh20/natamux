Natamux keeps agents in task shells from passing a gate, says what is left when a task is finished, and switches tasks without the terminals jumping. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Security

- Task shells get an agent token, not the daemon's token. With it, an agent cannot approve, skip or pass a stage, override a state or change project settings, and what it does is recorded as the agent's. It is not a sandbox. See [Agents run with your rights](https://natamux.github.io/docs/help/security-and-privacy/#agents-run-with-your-rights).
- Fix: on Windows, control bytes in a prompt, such as from an imported GitHub issue, reached PowerShell as key presses and could run a command. Natamux now removes them from every prompt.
- The **Stages** tab shows the **Check command** of every stage, and **Command** and **Arguments** whenever the file sets them. Before an import, Natamux lists every command in the file and asks once. See [Import and export](https://natamux.github.io/docs/guides/project-settings/#import-and-export).

## Finished tasks

- When a task is done or cancelled, a banner says the next step: commit, push, the pull request or removing the workspace. The **Terminal** tab shows a wrap-up with the changes, the push, the pull request, the branch and the last screen of each shell. See [When a task is finished](https://natamux.github.io/docs/guides/dashboard/#when-a-task-is-finished).
- One dialog removes the workspace. It says what goes and what stays, can also delete the branch, and keeps a workspace with changes. Then the task shows a summary with **Start a follow-up task**.
- A shell that a finished stage opened keeps the stage's name and shows **done** in the sidebar. The "State not known yet" icon is a ring with a dot. See [Status icons](https://natamux.github.io/docs/guides/status-icons/).

## Terminal

- Switching between tasks with several shells no longer makes the panes jump or redraw.

## Updates

- **Check for Updates…** shows a small popup while it checks and downloads. **Hide** or `Esc` closes it; the update goes on. See [Updates](https://natamux.github.io/docs/guides/desktop-app/#updates).

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
