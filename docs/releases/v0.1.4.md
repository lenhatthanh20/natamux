A terminal that draws like Ghostty and no longer breaks apart on a resize, a review banner in the workspace, and 25 fixes. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Terminal

- **Fix: words broke apart after a resize or a reconnect.** The first letter of each word sat at the right edge and the rest on the next row. A shell's screen is now kept by Natamux and drawn again for the size of each pane. When the same shell is open in two places, the pane you type in or click sets its size. See [Terminal](https://natamux.github.io/docs/guides/terminal/).
- **Like Ghostty.** Terminals draw with the GPU (WebGL), wait for the end of each screen update so Claude Code no longer flickers, and give emoji two columns.
- **History by memory.** Each shell keeps about 10 MB of history, like Ghostty's default: about 7,800 lines at 80 columns, 5,200 at 120 and 3,100 at 200.
- **Terminal font.** Choose it in **Account → Terminal font…**. The desktop app uses the `font-family` and `font-size` of your Ghostty config by default. See [Font and drawing](https://natamux.github.io/docs/guides/terminal/#font-and-drawing).

## Dashboard

- **Review banner.** A task in review shows **Approve** and **Send back** in its workspace, at any window size and on a phone.
- **Next git step.** With changed files and nothing committed, the header offers **Commit…** and says why Push waits. The commit toast offers **Push**, and the push toast offers **Create pull request**. The **Changes** tab shows how many files there are to commit.
- **Needs you** rows say what the agent asks or why it failed. A failed agent shows in red, and a long message has **More**.
- **Board:** empty columns fold, so the columns with tasks fit. **Table:** the row menu has the task actions (Start agent, Retry, Approve, Mark ready, Block, Cancel), and agents show by name.
- **Start a task** has its own button next to **Add task**.
- **Progress** is in the details panel, which is open by default beside a workspace. The **Docs** tab shows Markdown as formatted text. See [Progress](https://natamux.github.io/docs/concepts/stages/#progress).
- **Remove finished workspaces** in the menu of a project. Any project can be removed, and the app opens with no project: use **File → Add Project…**.
- A task whose agent waits for background work stays running and is not counted as quiet.

## Fixes

- **Windows:** a task title with a typographic quote (’), often from an imported issue, could end the PowerShell launch line early and run the rest as commands.
- **No agent, a plain shell** started Claude Code anyway with the default stages.
- `natamux task create` failed when there was no project named `default`. It now uses the project of the task terminal or the only project, and takes `--repo <id>`. See [CLI](https://natamux.github.io/docs/reference/cli/).
- Removing a workspace no longer leaves a task running with no agent when git refuses to remove the worktree, and works with checked-out submodules.
- **Answer in terminal** shows and focuses the waiting shell, even when it is hidden; focus no longer jumps between shells by itself.
- On Windows and Linux, **Cancel** on the quit dialog keeps the app open with its window.
- A check while an update is ready looks for a newer release first.
- More fixes in the **Start a task** dialog, Escape in a terminal beside the details sheet, the palette's shell jump and the reconnect of the live connection. See the [changelog](https://natamux.github.io/docs/help/changelog/).

## Before you open it

This release is **not signed** with an Apple certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

An update from v0.1.2 or v0.1.3 does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
