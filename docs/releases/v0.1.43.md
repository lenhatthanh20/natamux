A stage's settings have a checkbox to run it in a terminal of its own, and turning that off now moves the stage back to Terminal 1 at its next start. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Stages

- The stage settings in **Project settings → Stages** have a **Run in a terminal of its own** checkbox (`ownShell`). Checked, the stage runs in Terminal 5 with a new session. Unchecked, it runs in Terminal 1 with the task's agent. Unchecking also clears the stage's **Agent** and **Arguments** when it can no longer have them. The **Agent** help names the terminal the stage runs in. See [The Stages tab](https://natamux.github.io/docs/guides/project-settings/#the-stages-tab) and [Stages in their own terminal](https://natamux.github.io/docs/concepts/stages/#stages-in-their-own-terminal).

## Fixes

- A stage that started in Terminal 5 kept it after `ownShell` was turned off. Now an `ownShell` change moves the stage to the terminal the settings give at its next start. A lane of a group keeps its terminal. See [Choose a model](https://natamux.github.io/docs/concepts/stages/#choose-a-model).

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
