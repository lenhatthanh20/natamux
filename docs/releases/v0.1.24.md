Natamux checks the signature of every update before it installs it, draws every task state with a status icon of its own, and starts Copilot CLI 1.0.97 again. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Updates

- The app now installs an update only when `SHA256SUMS.txt` of the release is signed with the Natamux release key, which never leaves the owner's Mac. A missing or wrong signature, or a signature of another release, stops the update before the download. A copy that cannot update itself, such as on Windows, is not shown an unsigned release either. See [Updates](https://natamux.github.io/docs/help/security-and-privacy/#updates).
- From this release on, `SHA256SUMS.txt.minisig` is on every release, so you can check your download with `minisign`. See [Verify the download](https://natamux.github.io/docs/getting-started/install/#verify-the-download).
- v0.1.23 and earlier do not check the signature. Update to this version to get the check.

## Status icons

- Every task state has its own shape, the same in the task table, the palette, the pane tabs, the terminal header, the sidebar and the stage markers. A running task blinks once every 2 seconds instead of spinning, busy buttons show a stepped spinner, and loading lists fade instead of shimmering. Sidebar icons are larger. See [Status icons](https://natamux.github.io/docs/guides/status-icons/).

## Agents

- Fix: Copilot CLI 1.0.97 refused to start with `--no-alt-screen`, which it no longer has, so every Copilot stage failed. Natamux no longer adds it. Copilot again runs in its own full screen, with its scrollbar as a light line at the right edge. See [What Natamux runs](https://natamux.github.io/docs/agents/copilot/#what-natamux-runs).

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
