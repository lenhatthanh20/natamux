Delete a task, a faster dashboard, and a fix for Cursor tasks that stopped at the next stage. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Delete a task

- **Delete task** is in the menu of a row in the task table, in the **...** menu of the details panel, and in the menu of a workspace row. It asks first.
- It deletes the task, its notes and its history, and the worktree when there is one. When the worktree has changes that are not committed, nothing is deleted and the message says so.
- **Remove workspace** still deletes only the worktree and keeps the task. **Cancel task** still keeps the task in the list.

See [Sidebar](https://natamux.github.io/docs/guides/dashboard/#sidebar).

## Faster

- **The dashboard opens faster.** The code for the Markdown view, the file editor and the terminal loads only when you open them.
- **Less GPU memory.** A terminal that is hidden for 10 seconds gives its GPU drawing back, and takes it again when you show it. This helps when many tasks run at once.
- **Changed-file counts load faster.** When many workspaces ask for their counts at the same time, Natamux reads each one once and runs at most 4 reads at once.
- When a view cannot load its code, it shows an error in its place instead of a blank panel.

## Fixes

- **Cursor did not send the prompt of the next stage.** When you approved a stage (for example **Review**), Cursor showed the prompt of the next stage but did not send it, and you had to press Enter. Natamux pasted the prompt and pressed Enter in one piece, and Cursor ignores an Enter that comes with the end of a paste. Natamux now presses Enter a moment later. Review comments and failed-check messages are sent the same way.

The Intel Mac and Linux builds are paused. The last release with them is [v0.1.2](https://github.com/lenhatthanh20/natamux/releases/tag/v0.1.2). On those systems **Check for Updates…** finds this version but no file for it, and shows an error. Keep using v0.1.2 there.

## Before you open it

This release is **not signed** with an Apple certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
