A fix for Cursor tasks that stopped at the next stage. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Fixes

- **Cursor did not send the prompt of the next stage.** When you approved a stage (for example **Review**), Cursor showed the prompt of the next stage but did not send it, and you had to press Enter. Natamux pasted the prompt and pressed Enter in one piece, and Cursor ignores an Enter that comes with the end of a paste. Natamux now presses Enter a moment later. Review comments and failed-check messages are sent the same way.

## Download

| System | File |
|---|---|
| macOS, Apple silicon (M1 and later) | `Natamux-mac-arm64.dmg` |

`SHA256SUMS.txt` lists the checksum of every file.

The Intel Mac and Linux builds are paused. The last release with them is [v0.1.2](https://github.com/lenhatthanh20/natamux/releases/tag/v0.1.2). On those systems **Check for Updates…** finds this version but no file for it, and shows an error. Keep using v0.1.2 there.

## Before you open it

This release is **not signed** with an Apple certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
