Install or update Natamux with one command, and on macOS the app keeps Full Disk Access after an update. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Install

- Install or update the desktop app with one command: `curl -fsSL https://natamux.github.io/install.sh | sh` on macOS, Debian and Ubuntu, or `irm https://natamux.github.io/install.ps1 | iex` in PowerShell on Windows. The script checks the download against `SHA256SUMS.txt`, and its signature when `minisign` is installed. On macOS it clears the quarantine flag, so the first start is not blocked. It does not start the app. See [Install with one command](https://natamux.github.io/docs/getting-started/install/#install-with-one-command).
- The download button at the top of the homepage now goes to the install command instead of downloading a file.

## Desktop app

- The macOS app is signed with a Natamux certificate, so Full Disk Access and other privacy grants stay after an update. It is still not signed with an Apple certificate. The first update to this version needs the grant once more: in **System Settings → Privacy & Security → Full Disk Access**, remove the old Natamux entry with **−**, then add Natamux again. See [Full Disk Access on macOS](https://natamux.github.io/docs/guides/desktop-app/#full-disk-access-on-macos).
- A program in a Natamux terminal that needs the microphone, the camera, AppleScript or another privacy permission now gets a macOS prompt instead of being denied.

## Download

| System | File |
|---|---|
| macOS, Apple silicon (M1 and later) | `Natamux-mac-arm64.dmg` |
| macOS, Intel | `Natamux-mac-x64.dmg` |
| Windows 10 and 11, x64 | `Natamux-win-x64.exe` |
| Linux, any distribution | `Natamux-linux-x86_64.AppImage` |
| Debian, Ubuntu | `Natamux-linux-amd64.deb` |
| Linux, no install | `Natamux-linux-x64.tar.gz` |

`SHA256SUMS.txt` lists the checksum of every file.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
