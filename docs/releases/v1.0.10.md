Name a task's branch when it starts, and Natamux now follows the branch the task really uses. In the desktop app, the sidebar shows the task id, and the sidebar and the details share one width. One fix: the line beside the details panel is 1 px again. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Branches

- Name the branch of a task. **Start a task** has a **Branch** field after **Branch from**. It fills itself from the key at the start of the title, such as `ABC-12: Fix it`, and the project pattern, until you edit it. The project pattern is `git.branchName` in `.natamux.json`, with `{id}` and `{slug}`, and is in **Project settings > Stages**, **Branch name**. The CLI takes `--branch <name>` on `workspace create` and `agent start`, and the API takes `branch`. A branch that is local is checked out as it is. One only on `origin` becomes a local branch that tracks it. One checked out in another worktree fails with "Branch <name> is checked out in <path>". See [Branch name](https://natamux.github.io/docs/concepts/workspaces/#branch-name).
- Natamux follows the branch the task really uses. When an agent switches the worktree to another branch, the pull request lookup, the CI check, push and the branch delete use that branch. Natamux never takes the default branch this way. The event `workspace.branch-changed` records the switch.

## Desktop app

- Each row of the sidebar shows the task id before the title. Only the title is cut short. Private mode blurs the title and keeps the id.
- The sidebar and the docked details (the panel with its rail) share one width, from 280 to 480 px, 320 by default. Drag either edge to resize both. See [In the desktop app](https://natamux.github.io/docs/guides/dashboard/#in-the-desktop-app).

## Fixes

- The line between the terminals and the docked details panel was 2 px wide. Now it is 1 px, as beside the sidebar.

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
