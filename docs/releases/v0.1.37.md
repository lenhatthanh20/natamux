Agents come back after a restart, a notification opens its task, and the desktop app shows how many tasks need you. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Desktop app

- Click a notification to bring the window forward and open its task. See [Notifications](https://natamux.github.io/docs/guides/dashboard/#notifications).
- The app icon shows how many tasks need you: in the Dock on macOS, in the launcher on Linux. Windows shows no count.
- **File → Keep Computer Awake While Agents Run**, on by default: while an agent runs, the computer does not go to sleep on its own. See [Menu](https://natamux.github.io/docs/guides/desktop-app/#menu).

## Dashboard

- In the command palette, `Tab` changes the scope: **Needs you**, then each project that has a task, then no scope. Typed text searches inside the scope. Press `Backspace` with nothing typed to remove it. See [Command palette](https://natamux.github.io/docs/guides/dashboard/#command-palette).

## Terminal

- After a restart, opening a task brings back every agent of the task, not only the first one. An agent that crashed or was killed comes back too. An agent you quit stays quit. See [A shell after a daemon restart](https://natamux.github.io/docs/guides/terminal/#a-shell-after-a-daemon-restart).
- An agent you started by hand in a task shell comes back on its last conversation too. While it comes back, the sidebar shows it as an agent.
- A terminal hidden for 20 minutes is closed in the dashboard to save memory. Its shell keeps running, and the terminal opens again when you go back to it. A terminal on screen is never closed.
- Task shells get `LANG=C.UTF-8` when the daemon has no locale, so typed Vietnamese and other non-ASCII letters are no longer garbled. See [Task terminals](https://natamux.github.io/docs/reference/environment-variables/#task-terminals).
- **Find** counts the matches again after you switch **Match case** or **Use regular expression**.

## Fixes

- An agent's `git add` or `git commit` no longer fails on `index.lock` while the dashboard is open. The dashboard reads git status without the lock.
- A menu opened inside a dialog shows above the dialog, and focuses its first item.
- A double click on a row of the task table opens the row you clicked first.
- **Start agent** is no longer offered on a done or cancelled task.
- A subtask is in its parent's project unless you pick another one.
- A second fan out numbers its tries after the earlier ones, so there is no second `(try 2)`.
- **Save as template** cuts the name and title to the template limits instead of failing.
- The dialog to remove a workspace names the program that runs in a shell with no agent.
- The dashboard fonts load again.
- Screen readers no longer announce tasks that already needed you when the dashboard opened.
- The status bar says "1 needs you", and removing a workspace with one change says "1 change that is not committed".

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
