Terminals that look like a native terminal and stay fast under a flood of output, new fonts across the app, and each shell names the agent that runs in it. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Terminal look

- The terminal font is **JetBrains Mono** at 13px. Rows are as tall as the font (line height 1), and bold text is bold (700), as in Ghostty, VS Code and JetBrains IDEs.
- Natamux bundles the Nerd Font icons, as Ghostty does. Prompt themes such as Starship or Powerlevel10k and `eza --icons` show their icons without installing a Nerd Font.
- A new color palette, **Night**: a navy background with soft colors, in dark and light.
- When several panes show, the panes that do not have the focus are dimmed. Click one to type in it.
- A terminal without the focus shows its cursor as an outline, and its selection dimmer.
- Hold `Alt` while you scroll to scroll 5 times faster.

See [Font and drawing](https://natamux.github.io/docs/guides/terminal/#font-and-drawing).

## Fonts

- The diff in **Changes** and the file editor use JetBrains Mono, the font of the terminal, so code looks the same in a diff and in a shell.
- The text of the dashboard is in **Inter** at 13px, the UI font of JetBrains IDEs. Small labels such as ids and branches stay in Geist Mono.

## Faster terminals

- Up to 8 hidden terminals stay open. Going back to a terminal from **Changes**, or back to a task, shows it at once, without drawing the history again.
- A shell that prints a lot no longer slows down the page or the other shells. `Ctrl+C` shows the prompt again quickly.
- When the connection to a shell drops, for example after your computer sleeps or the network changes, the pane shows **Reconnecting.** and connects again by itself. The screen stays as it was, and the output you missed follows.
- After a daemon restart, the pane shows **The shell ended.** with **Start a new shell**.

See [Shells](https://natamux.github.io/docs/guides/terminal/#shells).

## Fixes

- Fix: an agent you typed into a new shell, such as `codex`, showed the agent of the task ("Claude Code") in the pane header. Shell panes and the **Agents** grid now show the agent that runs in each shell, and no agent for another program such as `vim`. Codex has its own icon.

## Before you open it

This release is **not signed** with an Apple certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
