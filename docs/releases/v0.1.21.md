Natamux gives each project a card in its own color in the sidebar, with a button for its settings, and lets you import and export project settings as a JSON file. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Sidebar

- Each project is a card in its own color, with its workspaces inside. The color comes from the project id, so it stays the same. See [Sidebar](https://natamux.github.io/docs/guides/dashboard/#sidebar).
- A gear next to **+** opens the project's **Settings** in one click. **Settings** stays in the project menu too.

## Project settings

- **Export** downloads the settings, edits included, as `<project>.natamux.json`. It is turned off while the **JSON** tab holds JSON that is not valid.
- **Import…** opens a `.json` file (up to 1 MiB) in place of the current settings. With edits not saved, it asks first. It does not save: check the settings, then click **Save**. Use it to copy settings from one project to another. See [Import and export](https://natamux.github.io/docs/guides/project-settings/#import-and-export).

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
