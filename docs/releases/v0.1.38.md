Subtasks now work on their parent's branch, and a new Settings dialog gathers the app-wide settings. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Tasks

- A subtask is now part of its parent's work. Its workspace starts from the parent's branch, and its pull request goes into the parent's branch. Natamux pushes the parent's branch first. See [Subtasks](https://natamux.github.io/docs/concepts/tasks/#subtasks).
- The parent waits for its open subtasks: its next stage starts when the last one is done, cancelled or deleted. Before that stage's agent starts, Natamux runs `git pull --ff-only` in the parent's worktree to bring in the merged work. A stage that is already running keeps running.
- A subtask's `context.md` ends with a `## Parent task` section: the parent's id, title, notes and the folder of its stage files.
- A subtask cannot depend on its parent.

## Dashboard

- **Add subtask…** in the row menu of the sidebar and the task table asks for a title and adds a draft subtask. See [Sidebar](https://natamux.github.io/docs/guides/dashboard/#sidebar).
- A new **Settings** dialog has Appearance (theme, UI size, terminal font), Desktop app (keep awake, automatic update checks) and a link to each project's settings. Open it with **Settings…** in the Account menu or `Mod+,`. See [Settings](https://natamux.github.io/docs/guides/dashboard/#settings).

## Desktop app

- **Settings…** (`Cmd/Ctrl+,`) in the app menu on macOS, and in the **File** menu on Windows and Linux, opens the Settings dialog. See [Menu](https://natamux.github.io/docs/guides/desktop-app/#menu).
- The window shows a spinner in its center from the start until the dashboard is ready, instead of a blank window.

## CLI

- `natamux task create <title> --parent <id>` makes a subtask. Without `--repo`, it is in the parent's project. See [task](https://natamux.github.io/docs/reference/cli/#task).

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. On Ubuntu 24.04 and later, if it does not start, add `--no-sandbox` or install the `.deb` instead.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `natamux-desktop`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
