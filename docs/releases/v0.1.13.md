The sidebar now gives each task the room it needs: a card with the question when an agent waits on you, two lines for work that goes on, and one line for finished tasks. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Dashboard

- A task that waits on you, failed or is blocked is a tinted card in the sidebar. It shows the agent's question, or why the task failed, on up to two lines. On a task that asks, **Answer** opens the terminal of the agent that asked. See [Sidebar](https://natamux.github.io/docs/guides/dashboard/#sidebar).
- A task that works, waits for review or is ready has two lines: the title and age, then the task id, the step and stage, the subtasks done, what the agent does now, the pull request and the agent's icon.
- A finished, cancelled or draft task is one short line.
- The icon before a title has its own shape for each state: a ring for ready, a dot that breathes while an agent works, a diamond for a question, a square for review, a triangle for a failure and a check for done. It reads without color too.
- Only the open task shows its shells and subtasks. Click a task, or press `Right` on it, to open it; the task that was open before folds. The chevron and the comet are gone, and rows no longer open by themselves.

## Before you open it

This release is **not signed** with an Apple certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
