Add your own agents in Settings, and see each task as a card in the sidebar. If you have v0.1.2 or later, the app updates itself to this version.

Guide: https://natamux.github.io/docs/

## Desktop app

- Add a custom agent in **Settings → Agents**: a built-in agent started with your own command, such as a shell function that points Claude Code at another model, or any other agent CLI. It shows in every agent picker, and a stage can use it like a built-in agent. The daemon keeps the list in `custom-agents.json`, not in the repo, so a cloned project cannot name a program to run. See [Custom agents](https://natamux.github.io/docs/guides/desktop-app/#custom-agents).
- The sidebar shows each task as a card: state, title, agents, stage, branch and diff. A task that waits for you shows its question with one button: **Answer**, **Open terminal** or **Open task**. Click a card to open or fold it; opening another task folds the last one. Right click opens the task menu. An open card lines up its chips, branch and terminal rows under the title.
- The **Progress** view shows the stages as a node flow. Groups fork and join, and a branch is an **If** box with one lane per path. Stage nodes keep their text and buttons inside the border in a narrow panel, and the "..." menu is gone: its actions stay on the node. See [Progress](https://natamux.github.io/docs/concepts/stages/#progress).

## Before you open it

This release is **not signed** with an Apple or Windows certificate.

- **macOS:** drag Natamux to Applications and open it once. macOS blocks it. Then open **System Settings → Privacy & Security** and click **Open Anyway**. If there is no such button, run:

  ```sh
  xattr -dr com.apple.quarantine /Applications/Natamux.app
  ```

- **Windows:** run `Natamux-win-x64.exe`. If SmartScreen shows **Windows protected your PC**, click **More info**, then **Run anyway**. The installer needs no administrator rights.
- **Linux AppImage:** run `chmod +x Natamux-linux-x86_64.AppImage`, then start it. If it does not start, start it with `--appimage-extract-and-run`, or install the `.deb` instead. The updater needs `curl`.
- **Debian and Ubuntu:** run `sudo apt install ./Natamux-linux-amd64.deb`. The app is `/opt/Natamux/natamux-app`.

An update from v0.1.2 or later does not need these steps.

See the [install guide](https://natamux.github.io/docs/getting-started/install/).
